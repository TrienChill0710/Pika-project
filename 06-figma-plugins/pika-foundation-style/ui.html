Foundation
Creates Pika's 4 Effect Styles — Elevation/card · hero · hero-accent · bar — from Semantic / elevation, the exact 4 shadows of the approved proof screens. Each is one layer: card 0 2 10 ink 5% (white cards, factstrip, glass blocks) · hero 0 12 30 ink 14% (navy gradient heroes, sheets) · hero-accent 0 12 30 lime 26% (the CTA and selected-slot glow) · bar 0 10 34 ink 14% (floating glass tab bar, summary bar). Every layer binds 5 properties (offset x/y · blur · spread · color) — change a token and the style updates. An optional 6th token type = inner makes that layer an inner shadow; without it, a drop shadow.
Creates 14 Text Styles — one per semantic typography role: Amount 52 · Hero 44 · Display 32 · Heading 24 · Title 20 · Body-lg 17 · Body / Body-bold 15 · Label / Label-bold 13 · Caption 12 · Micro / MicroCaps 11 · StatusBar 15. Font: Inter, 4 weights (Regular 400 · Medium 500 · Semi Bold 600 · Bold 700) — Pika uses no 800. Each style name lowercased is its semantic path, so values come from typography/{role}/* and only fall back to font/* primitives if Semantic was not imported.

Units: fontFamily · fontSize · letterSpacing (as Figma %) and fontStyle are bound to variables. lineHeight is written as a PERCENT literal (1.08 → 108%): the token is a CSS multiplier and Figma reads a bound number in the current unit, so binding it would mean 1.08%. Change a lineHeight token → run Generate again.
Reads Primitive tokens → draws a Color + Typography board on canvas. The plugin scans the Primitive collection and lists every color family (navy · lime · sky · neutral · positive · warning · negative · wash · static · transparent — 10 families, 66 swatches) as a swatch grid — each cell binds the variable + shows name & hex; builds the typography type scale (font family, weight, size, line-height, letter-spacing); draws spacing bars and radius boxes bound to the space/* and radius/* tokens; and shows every Elevation style on a card (run the Effect tab first).

The board's own chrome uses Pika's primitives (navy/900 header, lime/200 accent, wash/1 tint), so the Foundation page reads like the product. Note: the 8 gradient tokens are STRING variables and are not drawn here — they become Paint Styles by hand in Step 14.

Requires: run the Import Tokens plugin first so the Primitive collection exists. Generate creates/replaces a 🎨 Foundation page; Wipe removes the plugin-generated board.
