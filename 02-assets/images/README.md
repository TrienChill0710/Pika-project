# 02-assets/images/ — generated images · filled in Step 12 (optional at the start)

Photos and product images the UI needs (venue photos, products, banners…).
You do NOT add anything here at the start.

In **Step 12** Claude lists every image slot (`IMG01`, `IMG02`…) and writes one
image-generation prompt per slot in `07-claude-design-input/image-prompts.md`.
You generate each image (e.g. ChatGPT image generation), then save it here with the
exact file name Claude gives you, e.g. `IMG01-venue-hero.png`, and say "images done".

Claude Design then receives these files together with the spec, so the final UI shows
real images instead of placeholders. A slot with no file stays a labelled placeholder.
Only use images you generated or have the right to use.
