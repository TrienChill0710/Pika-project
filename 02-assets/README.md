# 02-assets/ — fill this in at the START, together with the brief

Claude checks all four sub-folders in Step 01 and warns you about anything missing.

| Folder | What to add | Required? |
|---|---|---|
| `logo/` | The real project logo (SVG or PNG). Colors come from it in Step 07. | **Yes** |
| `moodboard/` | 2–4 screenshots of UI styles you like (Mobbin, Dribbble, real apps). | **Yes** |
| `icons/` | The client's icon set (SVG) **or** `icon-library.txt` with the name of ONE open-source icon library. | **Yes** (one of the two) |
| `fonts/` | The project font files **or** `font-name.txt` with the name of ONE open-source font (e.g. Inter). | **Yes** (one of the two) |
| `images/` | Nothing at the start. In Step 12 you save here the images you generate from Claude's prompts (`IMG01-….png`). | No — Step 12 |

Only use assets you have the right to use: the client's own files, or free/open-source
fonts and icons whose license allows commercial use. Never use fonts or icons you don't own.

Missing logo, moodboard, icons or font → Claude can still run Steps 01–06,
but it will STOP before Step 07 until they are added.
