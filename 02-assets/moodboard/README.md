# 02-assets/moodboard/ — style references · REQUIRED

**At the start:** add 2–4 screenshots of UI styles you like (Mobbin, Dribbble, real apps).
This sets the general look.

**In Step 08:** Claude gives you 3 short search keywords (2–3 words) for each key screen
(e.g. "car rental", "date picker", "QR ticket").
Search with them one at a time and save 1–3 references per screen into `screens/`, one folder per screen:

```
moodboard/
  style-1.png  style-2.png …        ← general style (at the start)
  screens/
    S01-home/        ref-1.png …    ← same content + layout as your screen (Step 08)
    S05-car-detail/  ref-1.png …
```

General style images show the LOOK. Screen references show the CONTENT and LAYOUT.
With both, the AI builds each screen much more accurately.
