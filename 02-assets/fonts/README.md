# 02-assets/fonts/ — the project font · REQUIRED (one of the two options)

Option A — put the font files here (.ttf / .otf / .woff2).
Option B — create `font-name.txt` and write the name of ONE open-source font (e.g. Inter).

Only use fonts you have the right to use: the client's licensed font, or an open-source
font (e.g. SIL Open Font License). Do NOT use system fonts that can't be shared or
used outside their platform.
