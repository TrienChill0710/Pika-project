# 02-assets/icons/ — the icon set · REQUIRED (one of the two options)

Option A — the client has icons: put the SVG files here (one icon per file).
Claude uses them exactly as given and never redraws them.

Option B — no icon set: create `icon-library.txt` here and write the name of ONE
open-source icon library (e.g. Lucide, Phosphor, Tabler, Material Symbols).
Claude uses only that library on every screen.

Rules: one icon style for the whole product (same stroke, same corners, outline OR filled).
Never copy icons from other apps or from paid packs you don't own.
