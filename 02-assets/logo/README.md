# 02-assets/logo/ — the project logo (SVG or PNG) · REQUIRED

Upload the real file, not a screenshot. Claude takes the brand colors from it (Step 07).
The logo is always used exactly as-is — never redrawn or regenerated.

If the app has Dark mode or dark headers, also add a **logo for dark surfaces** (a light or transparent version)
from the client. If you don't have it, Claude asks for it in Step 01 — never invert or recolour the logo yourself.
