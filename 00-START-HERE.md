# 🎒 Start Here — Brief to Figma with Claude

This is the **blank kit**. Bring YOUR OWN project and run the same 8-phase / 17-step workflow as in the course.

## 1. Before you start — fill these (all required)

| Folder | What you add |
|---|---|
| `01-brief/` | The client brief — image, PDF or text. No client? Write 5–10 lines yourself. |
| `02-assets/logo/` | The real logo (SVG/PNG). |
| `02-assets/moodboard/` | 2–4 screenshots of UI styles you like. |
| `02-assets/icons/` | The client's SVG icons, **or** `icon-library.txt` with one open-source library (e.g. Lucide). |
| `02-assets/fonts/` | Font files, **or** `font-name.txt` with one open-source font (e.g. Inter). |

Claude checks all of this in Step 01 and warns you if something is missing.
Use only fonts and icons you are allowed to use commercially.

## 3. How to start

1. Open the **Claude desktop app** → **Cowork** → select THIS folder.
2. Type: **`Read Folder`**
3. Claude checks your inputs, tells you what it understood, and asks if it should start.
4. Say yes. After every phase Claude **stops at a gate** — review, answer, approve, continue.

## 4. The journey

| Phase | Steps |
|---|---|
| 1 · Brief | 01 Intake & input check · 02 Brief analysis & client questions |
| 2 · Market & users | 03 Business & competitors · 04 Users & personas |
