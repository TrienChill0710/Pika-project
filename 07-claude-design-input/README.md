# 07-claude-design-input/ — what you take to Claude Design (Step 12)

Everything Claude Design needs to build the full UI. What comes back goes to `08-final-ui/`.

- `master-spec.md` — brief + research + sitemap + user flows + palette + moodboard +
  tokens, every screen with every state. The single source of truth for Claude Design.
- `image-prompts.md` — one image-generation prompt per image slot (`IMG##`). Generate them first,
  save them in `02-assets/images/`, then attach them to Claude Design.
- `claude-design-prompt.md` — the prompt you paste into Claude Design.

Only these 3 files live here. The images stay in `02-assets/images/` — do not copy `02-assets/` into this folder.
